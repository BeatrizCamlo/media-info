# Midia Info
Este repositório é dedicado ao projeto de media-info atrelado a disciplina de Modelagem e Simulação Computacional durante o bacharelado em Tecnologia da Informação pela Universidade do Rio Grande do Norte.

O projeto tem como objetivo simular o efeito da regulamentação das redes sociais, com enfoque em desistimular publicações e suprimir conteúdo julgado como nocivo para as relações internas do país, e analisar os efeitos desta política à distribuição de conteúdo aos usuários da plataforma.

A hipótese deste trabalho assume que as medidas legislativas às redes sociais resultam na formação de clusters digitais, agrupamentos de usuários em um macroespaço de capitação de conteúdo homogêneo.

## Configuração de Ambiente para Execução

Certifique-se que possui python
```
python --version
python3 --version
```

Crie um ambiente virtual
```
python -m venv venv
```

Ative o ambiente virtual
```
source venv/bin/activate # linux ou macos
.\venv\Scripts\Activate # windows
```
Instale as dependências
```
pip install -r requirements.txt
```

Execute o programa
```
python3 main.py
```
